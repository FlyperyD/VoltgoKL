# VOLTGO — Заряд поруч (Калуш)
Статичний сайт для GitHub Pages: `Settings → Pages → Deploy from a branch → main / (root)`.

```
index.html      головна сторінка (усі розділи)
404.html        сторінка помилки
css/style.css   стилі
js/main.js      меню, калькулятор, опитування
js/config.js    контакти (Telegram / email) — заповніть самі
assets/         favicon.svg, station.svg
.nojekyll       вимикає обробку Jekyll
```
Цифри взято з документа «Виступ» (опитування 68 осіб, фінансова модель). Це розрахункові сценарії, а не гарантований результат.
