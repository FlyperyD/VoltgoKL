# VOLTGO — сайт для GitHub Pages

Це адаптивний односторінковий сайт українською мовою на основі матеріалів початкової презентації VOLTGO.

## Файли
- `index.html` — структура та текст сайту
- `style.css` — дизайн, адаптивність для телефонів і комп'ютерів
- `script.js` — мобільне меню та анімації появи блоків

## Як опублікувати через GitHub Pages
1. Створи новий репозиторій на GitHub.
2. Завантаж у корінь репозиторію всі три файли: `index.html`, `style.css`, `script.js`.
3. Відкрий **Settings → Pages**.
4. У розділі **Build and deployment** вибери **Deploy from a branch**.
5. Вибери гілку `main` і папку `/ (root)`, натисни **Save**.
6. Зачекай завершення публікації. GitHub покаже адресу сайту в цьому ж розділі Pages.
